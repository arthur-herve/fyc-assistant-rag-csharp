# Exercices de code (version C#)

dépôt principal, un kit de départ autonome (`depart/`).

| Séquence | Exercice | Forme | Point de départ |
|---|---|---|---|
| S1.3 | [Le transfert naïf](../exemples/s1.3-transfert-naif/README.md) | lecture guidée, trois questions | `exemples/s1.3-transfert-naif/` (autonome) |
| S2.2 | [Construire un cœur métier sans IA](s2.2-coeur-metier/README.md) | code à écrire, 20 tests fournis | `s2.2-coeur-metier/depart/` (solution .NET autonome, sans référence) |
| S3.1 | [Un test déterministe et une évaluation statistique](s3.1-evaluation-statistique/README.md) | tests à écrire, calcul de tolérance | le dépôt principal (`tests/Assistant.Tests/`) |
| S4.1 | [Ajouter un décorateur de validation](s4.1-decorateur-de-validation/README.md) | code à écrire, tests fournis | le dépôt principal, en retirant le décorateur (branche de départ à venir) |
| S5.1 | [Cas pratique : rendre maintenable une application IA existante](../cas-pratique/README.md) | refonte guidée par une grille | `cas-pratique/depart/` |

Les QCM et le test final ne sont pas ici : ils sont sur Moodle.
